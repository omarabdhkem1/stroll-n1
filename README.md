# stroll-n1 - موقع تجميع الروابط

موقع ويب بسيط وأنيق لتجميع جميع روابطك في مكان واحد. مثالي لمنشئي المحتوى واليوتيوبرز لمشاركة روابط قنواتهم وحساباتهم على مواقع التواصل الاجتماعي.

## المميزات ✨

- 📱 تصميم متجاوب يعمل على جميع الأجهزة
- 🎨 واجهة مستخدم أنيقة وجذابة
- ⚙️ لوحة تحكم سهلة الاستخدام
- 💾 حفظ تلقائي للبيانات في المتصفح
- 🔗 إضافة عدد غير محدود من الروابط
- 🌐 دعم كامل للغة العربية
- ⚡ سريع وخفيف بدون قواعد بيانات

## كيفية الاستخدام 🚀

### 1. فتح الموقع
افتح ملف `index.html` في متصفحك

### 2. تخصيص صفحتك
- اضغط على زر "⚙️ تعديل" في أسفل الصفحة
- أدخل اسمك أو اسم قناتك
- أضف وصفاً مختصراً
- أضف رابط صورتك الشخصية

### 3. إضافة الروابط
- في قسم "إضافة رابط جديد"
- اختر أيقونة (إيموجي)
- أدخل نص الرابط
- أدخل عنوان URL
- اضغط "إضافة رابط"

### 4. حفظ التغييرات
اضغط "حفظ التغييرات" وستُحفظ جميع بياناتك تلقائياً

## التقنيات المستخدمة 🛠️

- HTML5
- CSS3 (مع Flexbox و Animations)
- JavaScript (Vanilla JS)
- LocalStorage للتخزين المحلي

## أمثلة الاستخدام 💡

### لليوتيوبرز
- أضف رابط قناتك على يوتيوب
- أضف روابط حساباتك الاجتماعية
- أضف رابط للتواصل أو الدعم
- شارك رابط الصفحة في وصف الفيديوهات

### للمؤثرين
- اجمع جميع روابطك في مكان واحد
- سهّل على متابعيك الوصول لك
- حدّث الروابط بسهولة متى شئت
